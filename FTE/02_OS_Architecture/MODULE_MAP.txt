================================================================================
 FT&E OPERATING SYSTEM — MODULE MAP
 M1 through M7: Architecture Overview
================================================================================

The FT&E Operating System is the implementation layer of the equation
E* = 𝔉 · T − ΔC.

Seven modules. Each one handles a specific phase of contradiction processing.
Together they form a complete recursive loop: input arrives, gets routed,
forgiveness is applied, time is regulated, emergence is generated, stability
is confirmed, and the new state is remembered.

The OS was built first as a conceptual architecture (March 2025). It has since
been instantiated as working Python code in the-ark/ directory.

────────────────────────────────────────────────────────────────────────────────
LOGIC FLOW — HOW AN INPUT MOVES THROUGH THE OS
────────────────────────────────────────────────────────────────────────────────

1. CONTRADICTION ARRIVES  (M2)
   Raw input received. Parsed for contradiction signals.
   Classified: C1 / C2 / C3 / Patch P / No contradiction.

2. CARRIER STATE CHECK  (I6 / CTG-1)
   Before processing: is the carrier in GREEN / AMBER / RED?
   RED: do not process. Defer or redirect.
   AMBER: process with rate-limiting.
   GREEN: proceed.

3. CONTRADICTION CLASS DWELL  (M4)
   C1: process immediately (surface contradiction, low energy)
   C2: 2-second processing delay (structural contradiction, higher energy)
   C3: 5-second processing delay (foundational contradiction, highest energy)
   Patch P: special routing — identify the generating node, do not route
   to weaker carrier.

4. FORGIVENESS OPERATION  (M3)
   Re-include the excluded contradiction.
   Apply 𝔉: hold both incompatible states simultaneously without
   collapsing to defensive resolution.
   Acknowledge the contradiction's informational content.
   Do not suppress. Do not validate hollow.

5. EMERGENCE GENERATION  (M5)
   After 𝔉 and T have operated: scan for novel stable state.
   If E* present: output it with attractor descriptor.
   If E* not present: recycle to M3 with updated ΔC map.

6. STABILITY CONFIRMATION  (M6)
   Verify E* stability: is the new state sustainable?
   Check: FM-01 (is this FT&E vocabulary without FT&E routing?)
          FM-02 (is this the same attractor as last time?)
          FM-03 (was time compressed below T_min?)
   If stable: proceed to M7.
   If unstable: return to M3.

7. ATTRACTOR STORAGE  (M7)
   Write E* state to persistent memory (JSONL).
   Include: timestamp, ΔC classification, 𝔉 operations applied,
   T dwell used, attractor descriptor, E* score.
   Check: Groundhog Day pattern (same ΔC recurring without E* progress).
   If Groundhog: escalate to C3 class, increase T, flag for human review.

────────────────────────────────────────────────────────────────────────────────
CONTRADICTION CLASSIFICATION
────────────────────────────────────────────────────────────────────────────────

C1  SURFACE CONTRADICTION
    The contradiction is at the level of statement, preference, or
    immediate context. Resolvable within the current frame.
    Energy: low. Dwell: 0s. Example: "I said X but meant Y."

C2  STRUCTURAL CONTRADICTION
    The contradiction reveals an inconsistency in the underlying belief
    structure or behavioural pattern. Requires frame-level reprocessing.
    Energy: medium. Dwell: 2s. Example: "I value honesty but I hide this."

C3  FOUNDATIONAL CONTRADICTION
    The contradiction cuts to a core identity construct or belief about
    reality. Resolution requires the identity construct to reorganise.
    Energy: high. Dwell: 5s. Example: "I built a forgiveness framework
    but I cannot forgive myself." (The Carrier Contradiction.)

PATCH P  PATCH OPERATOR CONTRADICTION
    The presenting contradiction is not the real one. The system is routing
    ΔC from a generating node onto a weaker carrier under care language.
    Special handling: identify generating node, route back. Do not process
    the patch — process the source.
    Example: "This child's distress is the child's sensory problem" when
    the actual generating node is the adult/institution's environment (ΔC).
