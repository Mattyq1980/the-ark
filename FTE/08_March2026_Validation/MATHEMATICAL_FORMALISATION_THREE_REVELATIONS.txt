DEFINITION 4: M2 RECURSION DEPTH
────────────────────────────────────────────────────────────────────────────────

Let M2: S → 2^S be the classification operator that partitions the
contradiction space of a system into typed classes {C1, C2, C3, NC, P}.

Define M2 recursion depth d(s) for a system in state s:

  d = 0: System responds to ΔC but does not classify it
         (thermostat, simple feedback loop)
  d = 1: System classifies ΔC into categories and routes differentially
         (immune system, basic M2)
  d = 2: System models its own M2 classification process
         (self-aware system — can detect its own parsing errors)
  d = k: System models k-1 levels of its own classification process

d(s) is the maximum recursion depth at which M2(s) can operate on its
OWN outputs such that the resulting classification still changes the
system's routing behaviour.

This is well-defined and finite for any bounded system (a system with
finite state space cannot support infinite recursion).

  fund(L) = |dom(L)| / |D|  (fundamentality index)

empirical force in at least one domain (qualifying it as a physical law)
