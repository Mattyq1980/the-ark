  P1: THE CHANNEL CODING THRESHOLD IS e^(−ΔC/𝔉)

  The framework predicts that the probability of communication
  failure (error) should exhibit an exponential threshold of the
  form:

    P(error) ~ e^(−n · f(C, R))

  where f(C, R) is a function of channel capacity C (= 𝔉) and
  transmission rate R, and n is block length (= T).

  Specifically:
  - When R < C (rate below capacity, i.e., ΔC < 𝔉): error
    probability decreases EXPONENTIALLY with block length n
  - When R > C (rate above capacity, i.e., ΔC > 𝔉): reliable
    communication is IMPOSSIBLE regardless of block length
  - The transition is SHARP — there is a critical threshold at
    R = C, not a gradual degradation

  QUANTITATIVE PREDICTION: The error exponent should be of the
  form E(R) > 0 for R < C and E(R) = 0 for R ≥ C, giving:

    P(error) ≤ e^(−n·E(R))

  This is a SPECIFIC MATHEMATICAL CLAIM that can be verified or
  falsified against Shannon's actual theorems.

  FAILURE CONDITION: If error probability decreases as a POWER LAW
  (1/n^k) rather than exponentially with block length, or if the
  threshold at R = C is gradual rather than sharp, this prediction
  FAILS.


  P2: REDUNDANCY IS 𝔉-BANDWIDTH (CAPACITY BEYOND NOISE)

  The framework predicts that reliable communication requires
  EXCESS CAPACITY beyond the noise floor — the channel must have
  more processing capacity than the contradiction load demands.

  Specifically:
  - Reliable communication at rate R requires C > R (𝔉 > minimum)
  - The "excess" (C − R) functions as bandwidth for error
    correction — analogous to 𝔉 bandwidth in prior domains
  - Error-correcting codes should work by ADDING REDUNDANCY,
    which is structurally equivalent to increasing 𝔉 relative
    to ΔC

  Sub-predictions:
  P2a: Error-correcting codes exist that achieve rates
       arbitrarily close to C (the processing capacity is
       fully utilisable).
  P2b: These codes work by adding structured redundancy — extra
       bits that carry no new information but increase the
       system's ability to process noise.
  P2c: There should be a TRADE-OFF between rate (information
       density) and reliability (error probability) — you
       cannot simultaneously maximise both.

  FAILURE CONDITION: If reliable communication can be achieved
  WITHOUT redundancy (without excess capacity), or if codes
  cannot approach C, this prediction fails.


  P3: NOISE SUPPRESSION (ΔC → 0) PRODUCES TRIVIAL COMMUNICATION

  The framework predicts (from the Suppressed-ΔC pattern seen in
  12 prior domains) that a noiseless channel — one with zero
  contradiction load — should produce communication that is
  TRIVIALLY RELIABLE but structurally uninteresting.

  Specifically:
  - A noiseless channel (H(N) = 0, ΔC = 0) should have C = max
    entropy of the input — the full input alphabet is available
  - No error correction is needed — any encoding works
  - The "emergence" is trivial: reliable communication happens
    automatically, but no sophisticated coding structure develops
  - The interesting structures (error-correcting codes, capacity-
    approaching codes) emerge ONLY when noise is present (ΔC > 0)

  This mirrors the framework's prediction that ΔC is NECESSARY for
  non-trivial E*. Contradiction drives emergence.

  FAILURE CONDITION: If noiseless channels require sophisticated
  coding, or if the most interesting coding structures appear in
  noise-free settings, this prediction fails.


  P4: THE CHANNEL CAPACITY FORMULA ENCODES E* = 𝔉·T − ΔC

  The framework predicts that Shannon's capacity formula for the
  most fundamental channel type (AWGN — additive white Gaussian
  noise) should map onto the FT&E structure:

    C = W · log₂(1 + S/N)

  where W = bandwidth, S = signal power, N = noise power.

  Predicted structural mapping:
  - S/N (signal-to-noise ratio) IS the 𝔉/ΔC ratio
  - W (bandwidth) IS the T-window (channel uses per second)
  - C (capacity) IS the E* rate — the maximum achievable emergence
  - The logarithm compresses the ratio, consistent with the
    exponential threshold appearing in error probability

  QUANTITATIVE PREDICTION: The capacity should be a MONOTONICALLY
  INCREASING function of S/N (= 𝔉/ΔC) and ZERO when S/N = 0
  (when noise completely overwhelms signal). Specifically:
  - C → 0 as S/N → 0 (zero 𝔉 relative to ΔC → no emergence)
  - C → ∞ as S/N → ∞ (unlimited 𝔉 relative to ΔC → unlimited
    potential emergence)
  - C = 0 when W = 0 (zero T-window → no emergence regardless
    of 𝔉/ΔC ratio)

  FAILURE CONDITION: If the capacity formula depends on something
  OTHER than the signal-to-noise ratio and bandwidth, or if
  capacity is non-monotonic in S/N, this prediction fails.


  P5: THERE EXISTS A T-MINIMUM FOR E* (CONVERSE THEOREM)

  The framework predicts (from I3 — T is irreducible) that there
  should be a MINIMUM block length required for reliable
  communication at any given rate below capacity.

  Specifically:
  - For rate R < C, there exists a minimum n* such that for
    n < n*, P(error) cannot be made small regardless of the code
  - This is the converse of the channel coding theorem — it says
    you CANNOT communicate reliably with insufficient T
  - As R → C (approaching the threshold), n* → ∞ (the required
    T-window diverges at the critical point)
  - This mirrors the T-divergence seen at phase transitions
    (critical slowing down, Test #7)

  FAILURE CONDITION: If reliable communication can be achieved

  if there is no converse theorem establishing a minimum block
  length, this prediction fails.
