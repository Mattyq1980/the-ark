𝔉 (FORGIVENESS) — Immune tolerance / regulatory capacity

  The immune system must distinguish self from non-self. But "non-self"
  is not always dangerous — commensal gut bacteria, food proteins,
  foetal tissue during pregnancy, and the body's own cells during
  normal turnover are all "foreign" or "different" in some sense.

  𝔉 in immunology = the system's capacity to TOLERATE non-threat
  foreignness rather than attacking it. This is mediated by:
  - Regulatory T cells (Tregs) — specialised cells that SUPPRESS
    immune responses against self and benign foreign agents
  - Central tolerance — deletion of self-reactive T cells in the
    thymus during development
  - Peripheral tolerance — suppression of self-reactive cells that
    escape central tolerance
  - Oral tolerance — learned non-reactivity to food antigens

  Higher 𝔉 = more tolerance capacity = the system can encounter
  foreignness without mounting a destructive response.
  Lower 𝔉 = hyperreactive = the system attacks indiscriminately.

  𝔉 = 0 prediction: A system with NO tolerance capacity will attack
  self-tissue. This IS autoimmune disease. It should be destructive,
  chronic, and self-perpetuating — because the "pathogen" (self) can
  never be eliminated.

  Proxy variable: Treg cell count/function, cytokine balance
  (anti-inflammatory vs pro-inflammatory), presence/absence of
  autoantibodies.

T (TIME) — Duration of immune processing

  Adaptive immunity does not happen instantly. After encountering a
  pathogen, the immune system requires TIME to:
  - Recognise the specific antigen (antigen presentation)
  - Activate and clonally expand the correct T and B cells
  - Mount an effective response (antibody production, cytotoxic killing)
  - Form memory cells for future encounters

  T_min = insufficient processing time. If the immune response is
  too slow or the processing time is cut short (e.g., by
  immunosuppressive drugs, or overwhelming pathogen load that kills
  the host before adaptive immunity engages), no effective
  immunity develops.

  T_viable = sufficient time for full adaptive response. Pathogen
  cleared, memory cells formed, system returns to homeostasis
  with permanent new capability (immunological memory).

  T_max = excessive/prolonged immune activation. Chronic inflammation.
  The immune response continues beyond the point of utility, causing
  tissue damage. Cytokine storms. Sepsis. The system over-processes
  and damages itself.

  Proxy variable: Days from infection to clearance, duration of
  inflammatory markers, persistence of activated immune cells.

────────────────────────────────────────────────────────────────────────────────

ΔC (CONTRADICTION LOAD) — Pathogen virulence / antigenic challenge

  The "contradiction" the immune system must process is the pathogen
  itself — a foreign entity that violates bodily integrity.

  C1 (Acute/Surface): Minor infections. Common cold. Low virulence,
  low pathogen load. The innate immune system may handle it without
  full adaptive engagement. Minimal tissue damage.

  C2 (Structural): Significant infections requiring full adaptive
  immune response. Influenza, bacterial pneumonia, novel pathogens.
  The system must mobilise substantial resources. Tissue damage
  occurs during the battle (fever, inflammation, immune-mediated
  tissue destruction). Recovery requires days to weeks.

  C3 (Existential): Overwhelming infection, sepsis, or immune
  evasion by the pathogen (HIV, certain cancers). The contradiction
  exceeds the system's processing capacity. Without intervention,
  system failure (death) occurs.

  Also: SUPPRESSED ΔC — pathogens that evade detection (latent
  viruses like herpes, tuberculosis dormancy, cancer cells that
  downregulate MHC) represent contradiction that is PRESENT but
  HIDDEN from the processing apparatus. Predicted to be dangerous
  precisely because it accumulates without being processed.

  Proxy variable: Pathogen virulence, pathogen load (titre),
  tissue damage markers, immune evasion mechanisms.

E* (EMERGENCE) — Immunological memory

  After successful immune response, the system is permanently changed.
  It now possesses MEMORY CELLS — long-lived B and T cells that can
  recognise the specific pathogen and mount a rapid response upon
  re-encounter.

  Key prediction: E* is NOVEL, not restorative. The post-infection
  immune system is not the same as the pre-infection immune system.

  The system does not return to its pre-infection state. It goes
  THROUGH the contradiction and emerges with new structure.

  Proxy variable: Presence of memory B/T cells, antibody titres,
  speed of secondary immune response vs primary.
