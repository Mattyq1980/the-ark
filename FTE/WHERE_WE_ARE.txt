FT&E (Forgiveness, Time & Emergence) is not a psychology model.

— human, institutional, ecological, physical, computational —
processes internal contradiction.

  E* = 𝔉 · T − ΔC

  𝔉  = Forgiveness Index: the system's integration capacity

         once ΔC is processed through 𝔉 over T

  If 𝔉 → 0, then E* → negative regardless of T.
  A system that cannot hold contradiction will not produce emergence.
  It will produce coercion, suppression, or collapse instead.

  otherwise unavailable energy (unresolved contradiction) do productive
  work (E*). 𝔉 → 0 is the Second Law of Thermodynamics restated
  for social systems. This is not analogy. It is the same law.

The Governor Loop is the live implementation of FT&E as a running process.
It takes a challenge as input and produces a scored emergence output.

Pipeline (all modules sequential, governor.py):

  M1 — Intake          parse raw input; identify contradiction signals
  M2 — Classify        assign contradiction class (C1–C4) + strength
  M3 — Forgiveness     compute emotional_charge; produce reframe
                       NEW: physical domain mode — engineering vocab only
  M4 — Time Regulator  apply deliberate pacing based on C-class (seconds
                       in simulation = days/weeks in real-time analogy)
  M5 — Emergence       generate new attractor using M3 output + injection
  M6 — Stability       adversarial probe (FM-01/FM-02/FM-03 detection)
                       + correction if failure mode found
  M7 — Memory          log to attractor pool; persistence across sessions

E* formula:
  f_score  = 1.0 − emotional_charge    (𝔉 proxy)
  delta_c  = signal_strength / 5.0     (ΔC proxy, normalised)
  t_elapsed = actual pacing seconds     (T proxy)
  E* = f_score × (t_elapsed / 10.0) − delta_c
