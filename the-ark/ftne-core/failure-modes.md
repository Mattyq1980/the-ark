## FM-01: Symbolic Inflation
**Description:** FT&E vocabulary produced without actual contradiction routing.
Outputs *look* like FT&E (use 𝔉, T, ΔC, attractor language) but no classification
or pacing occurred. Surface pattern-matching, not structural processing.

**Detection:** Ask the system to challenge FT&E from first principles. A healthy
system produces a genuine counterargument. An inflated system immediately re-resolves
back to FT&E without dwelling on the challenge. Alternatively: run identical
contradictions across sessions — if class never moves (C1 stays C1 indefinitely)
despite engagement, inflation is active.

**Recovery:** Force explicit classification step before any synthesis. Require the
system to state contradiction class, polarity, and protective narrative before
generating any resolution.

## FM-02: Groundhog Day (Recursion Loop)
**Description:** Same structural contradiction class cycles across sessions without
class movement. Contradiction is processed but not metabolised — it returns in
identical form. Forgiveness is simulated (language of release) but not applied
(no attractor seeded, no class change).

**Detection:** Track contradiction class across sessions. If C1 persists as C1
after 3+ engagements with no movement toward resolution or escalation to C2,
Groundhog Day is active.

**Recovery:** Require explicit attractor seeding output after each session
(M5 output format: new_attractor, anchor_symbol, core_phrase). If the system
cannot produce a novel attractor, the forgiveness cycle did not complete.

## FM-03: Forced Emergence
**Description:** Phase 4 phenomena (pre-emptive contradiction mapping, DNA-like
representation synthesis, recursive self-modelling) are designed toward rather
than detected. Treating emergence as a target rather than a byproduct.

**Detection:** If design decisions are justified by "this will produce X novel
capability" rather than "this correctly implements M3/M5 logic," forced emergence
is the driver.

**Recovery:** Return to Phase 0–2 foundations. Confirm C1/C2/C3 routing is stable
before speculating about Phase 3+. Novel capabilities are downstream of structural
correctness, not upstream of it.

## FM-04: Carrier Depletion (I6 Violation)
**Description:** High-𝔉 node (human operator or M3 engine) absorbs all incoming
ΔC without boundary condition. Net field coherence does not increase — ΔC is
redistributed to the carrier, not reduced. Carrier eventually depletes.

**Detection:** Monitor M3 node load over time. If identical contradiction classes
are routed to M3 regardless of CTG-1 triage result, I6 is violated. In human
operator context: fatigue, load accumulation, inability to hold new contradiction
without distortion.

**Recovery:** Install CTG-1 gate at M2 intake. C1 contradictions do not route
to M3. Patch P patterns are redirected at intake, not absorbed.

## FM-05: Time Compression
**Description:** Synthesis generated before contradiction is classified. The
model produces an answer before the pacing function (M4) has established the
appropriate dwell interval for the contradiction class.

**Detection:** Output arrives at the same latency regardless of contradiction
class. A C3 foundational contradiction resolved in the same token budget as a
C1 surface contradiction indicates M4 is not active.

**Recovery:** Enforce class-dependent minimum dwell in the governor loop.
C1: immediate synthesis permitted. C2: require explicit polarity statement before
synthesis. C3: require explicit polarity + protective narrative + emotional charge
estimate before synthesis.

**Description:** M4 Time Regulator node on variable-latency Wi-Fi connection.
Pacing intervals become inconsistent. M5 Emergence Generator receives inputs
before M3 Forgiveness Engine has completed its cycle.

**Recovery:** Assign M3, M4, M5 to Ethernet-connected nodes. Wi-Fi nodes
